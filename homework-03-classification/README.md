# Homework 3 — Classification

This homework is part of my **Data Science for Health Informatics** coursework.

## Overview

The project uses the **UCI Adult Census Income dataset** to build binary classification models predicting whether an individual's income is:

- `<=50K`
- `>50K`

The notebook includes:

- Exploratory data analysis
- Data preprocessing and missing-value handling
- Feature encoding and selection
- Class imbalance analysis
- Stratified train-test splitting
- Cross-validation
- Comparison of 10 classification models
- Accuracy, precision, recall, F1-score, training time and prediction time
- Evaluation of the best model on the test set

## Models

The notebook compares variants of:

- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes

## Tools

Python, Pandas, NumPy, Matplotlib and Scikit-learn.
