# Homework 1 — Exploratory Data Analysis

## Overview

Exploratory Data Analysis (EDA) of the UCI Adult Census Income Dataset.

This project was completed as part of my **Data Science for Health Informatics** coursework.

## Dataset

The Adult dataset contains demographic, educational, employment and income-related information from U.S. Census Bureau data.

**Source:** UCI Machine Learning Repository  
https://doi.org/10.24432/C5XW20

## Analysis

The notebook demonstrates:

- Data understanding and initial dataset appraisal
- Loading and combining data using Pandas
- Feature selection
- Data type assignment
- Feature renaming
- Missing-value management
- Univariate analysis
- Bivariate analysis
- Data visualization
- Pearson correlation
- Interpretation of analytical results

## Tools

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
